## Getting Involved
---

There are many ways to get involved with this project and help with its development.
The sections below might give you a starting point, but feel free to [get in contact](contact.md) with your own suggestions as well.
Any help is appreciated!

**Feedback, Feature Requests and Bug Reports**

Let me know what you like or dislike about the program.
Was it easy to get started with?
What do you use it for? Are there specific features you wish it had?
And of course, be sure to report any bugs or other problems you encounter.
If you have a GitHub account, you can also use the project's [issue tracker](https://github.com/bow-simulation/virtualbow/issues) directly.
If you feel adventurous, try the [development version](https://github.com/bow-simulation/virtualbow/releases/tag/latest) and test upcoming features before they are released.

**Software Development**

VirtualBow is currently written in two programming languages: C++ with the Qt framework for the user interface, and Rust for the computational core.
The source code is hosted [on GitHub](https://github.com/bow-simulation/virtualbow), where the README explains how to build the program and how to contribute.
There are always lots of things to implement or improve, from the user interface down to the simulation model and the numerical methods.
Have a look at the [issue tracker](https://github.com/bow-simulation/virtualbow/issues) and [milestones](https://github.com/bow-simulation/virtualbow/milestones) if you need ideas.
Or simply get in contact and I will gladly help you get started.

**Validation of Simulation Results**

If you have used this program to design a bow and then actually built it, let me know how the simulation results compare to the real thing.
Bonus points if you have the equipment to measure things that are otherwise hard to check.
